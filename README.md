# Loss-Aware Synthetic Data Generation
**Estimating Utility Loss and Preventing It**

This repository contains the source code and documentation for our final project. The main goal is to investigate methodologies for measuring and mitigating the utility loss introduced during synthetic data generation through loss-aware optimization.

## 🎯 Project Overview
The generation of synthetic data presents a fundamental trade-off between preserving individual privacy and retaining the statistical utility of the original dataset. 

This project is divided into two main phases:
1. **Measurement (Utility Loss Estimation):** Quantifying the gap between real and synthetic data in terms of distributional fidelity (MMD, EMD), feature correlation preservation, and downstream predictive performance, while simultaneously monitoring privacy constraints (DCR, Inference Risk, etc.).
2. **Prevention (Loss-aware Optimization):** Exploring the integration of explicit penalty terms within the training objectives of synthetic data generators to systematically balance utility and privacy during the training phase.

### Expected Deliverables
* **Computational Framework:** A robust toolset for estimating utility loss and evaluating privacy guarantees.
* **Architecture Analysis:** Identification of generative architectures that inherently minimize information loss.
* **Loss Function Design:** Implementation and empirical validation of a novel multi-objective loss function.
